# StressPulse: installable HRV stress monitor (static build)

**Open the app: <https://barryshen1.github.io/stresspulse-app/>**

StressPulse turns Apple Watch heart-rate variability (HRV) into a 0–100 stress estimate, compared with your own 30-day baseline. It has five screens: Today, Trends, a watch-face preview, Habits and Settings (You). Ask Pip explains the numbers. The interface is in English and 简体中文. It starts with 60 days of synthetic demo data.

This repository holds only the built static site that GitHub Pages serves. It is generated by the private source repository's `scripts/build-pages.sh`, so please don't edit it by hand.

- **Installable:** in Safari on iPhone use Share → Add to Home Screen; in Chrome or Edge use Install app. After one visit the app also opens offline.
- **Your data stays local:** your Apple Health export (`export.zip` or `export.xml`, imported under You) is parsed in the browser and stored only in this browser's local storage. There are no accounts, no analytics and no StressPulse server.
- **AI is optional, off by default, and bring-your-own-key:** if you switch on You → AI assistant and save your own OpenAI API key, Ask Pip sends a compact summary of your numbers and your question **directly from your browser** to OpenAI, or to an OpenAI-compatible base URL you set. Usage is billed to your account. The key is stored unencrypted in local storage, and on `barryshen1.github.io` every Pages site of this account shares that storage. Use a restricted key with a spending limit, and press Clear key when you are done.
- **Not medical advice:** HRV-based stress is a wellness estimate, not a diagnosis.
- **Source is private:** the source code (web app, native iOS/watchOS app, docs, CI) lives in a private repository. This repository contains build output only.
